# Changelog

## 1.0.0

First release of the Plataine AI Agents plugin for Claude.

- Claude plugin with the Plataine AI Agents skill.
- Claude Desktop extension that connects Claude to the Plataine AI Agents of a TPO environment.
- Sign-in with the user's own TPO account, so TPO permissions and the audit trail apply.
- Conversation memory across follow-up questions.
- Charts from the agents displayed in Claude.
- Approval flow for actions that need the user's decision.
- Clear guidance in Claude when settings are missing or the sign-in is refused.
